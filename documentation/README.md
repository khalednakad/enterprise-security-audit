# VORTEX SECURE Documentation

## Overview

This directory contains the primary cybersecurity audit documentation for the VORTEX SECURE simulated enterprise environment.

The documentation supports the assessment of the organization's cybersecurity posture, security controls, enterprise risks, critical assets, audit findings, remediation recommendations, and continuous security improvement activities.

The **NIST Cybersecurity Framework (CSF) 2.0** is the primary cybersecurity framework used throughout the assessment.

Supporting standards and control references include:

- NIST SP 800-53 Rev. 5
- ISO/IEC 27001:2022
- CIS Critical Security Controls v8

# NIST CSF 2.0 Alignment

The documentation supports all six functions of the **NIST Cybersecurity Framework (CSF) 2.0**.

| NIST CSF 2.0 Function | Primary Documentation |
|---|---|
| Govern | Company Profile, Audit Scope, Risk Assessment, Security Controls |
| Identify | Asset Inventory, Risk Assessment, Audit Scope |
| Protect | Security Controls, Recommendations, Audit Findings |
| Detect | Security Controls, Audit Findings, Risk Assessment |
| Respond | Security Controls, Audit Findings, Recommendations |
| Recover | Security Controls, Recommendations, Lessons Learned |

The six functions are treated as an interconnected and continuously improving cybersecurity lifecycle.

The **NIST Cybersecurity Framework (CSF) 2.0** is the primary framework used throughout the VORTEX SECURE security audit project.

# Continuous Improvement

Cybersecurity risk is not static.

The documentation should be reviewed and updated whenever significant changes occur to:

- Organizational structure
- Employees
- Customers
- Business services
- Network architecture
- Cloud infrastructure
- AI systems
- Security technologies
- Third-party relationships
- Geographic operations
- Legal requirements
- Regulatory requirements
- Threat landscape

Continuous auditing, monitoring, risk assessment, remediation, testing, training, and documentation updates are therefore considered essential components of the organization's long-term cybersecurity strategy.

---

# Assessment Disclaimer

VORTEX SECURE is a simulated enterprise environment created for educational and portfolio purposes.

The documentation, assets, architecture, security controls, risks, findings, recommendations, and organizational characteristics represent the assumptions and assessment results of the simulated case study.

The documentation should not be interpreted as evidence of:

- A real-world security audit
- ISO/IEC 27001 certification
- NIST certification
- Regulatory approval
- A production penetration test
- Complete vulnerability discovery
- Elimination of cybersecurity risk

The project demonstrates the practical application of cybersecurity audit, risk assessment, security control evaluation, governance, and continuous improvement principles using **NIST Cybersecurity Framework (CSF) 2.0** as the primary assessment framework.
