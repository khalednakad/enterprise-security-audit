# References

This directory contains the authoritative security frameworks, standards, and guidance referenced during the VORTEX SECURE security audit project.

The references provide the foundation for the assessment methodology, security controls, risk management approach, AI security considerations, governance practices, and continuous improvement recommendations.

---

## Primary Assessment Framework

### NIST Cybersecurity Framework (CSF) 2.0

**Organization:** National Institute of Standards and Technology (NIST)

**Role in this project:** Primary cybersecurity assessment framework.

NIST CSF 2.0 is the principal framework used throughout the VORTEX SECURE security audit.

The assessment is organized around the six CSF 2.0 Functions:

- Govern
- Identify
- Protect
- Detect
- Respond
- Recover

The framework is used to structure:

- Cybersecurity governance
- Risk identification
- Asset management
- Security controls
- Detection capabilities
- Incident response
- Recovery
- Continuous improvement

Official reference:

https://www.nist.gov/cyberframework

Publication:

The NIST Cybersecurity Framework (CSF) 2.0

https://www.nist.gov/publications/nist-cybersecurity-framework-csf-20

## AI Security Reference

### NIST Artificial Intelligence Risk Management Framework (AI RMF) 1.0

**Organization:** National Institute of Standards and Technology (NIST)

**Role in this project:** Supporting framework for AI-specific security and risk considerations.

The NIST AI RMF is referenced because the VORTEX SECURE environment contains:

- Foundation Models
- Fine-tuned Models
- Training Datasets
- AI Agents
- RAG systems
- AI Compute Infrastructure
- AI-related intellectual property

The framework provides guidance for managing risks associated with the design, development, deployment, use, and evaluation of AI systems.

Official reference:

https://www.nist.gov/itl/ai-risk-management-framework

Publication:

Artificial Intelligence Risk Management Framework (AI RMF 1.0)

https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10

## AI RMF Playbook

### NIST AI RMF Playbook

**Organization:** National Institute of Standards and Technology (NIST)

**Role in this project:** Supporting guidance for operationalizing AI risk management.

The AI RMF Playbook provides suggested actions and implementation guidance related to the four AI RMF functions:

- Govern
- Map
- Measure
- Manage

It is used as a supporting reference for the project's AI security considerations and recommendations.

Official reference:

https://www.nist.gov/itl/ai-risk-management-framework/nist-ai-rmf-playbook

## Information Security Management Reference

### ISO/IEC 27001:2022

**Organization:** International Organization for Standardization (ISO) and International Electrotechnical Commission (IEC)

**Role in this project:** Supporting reference for information security management and continuous improvement.

ISO/IEC 27001:2022 defines requirements for an Information Security Management System (ISMS) and supports risk-based management of information security.

Relevant concepts considered in this project include:

- Information security governance
- Risk management
- Protection of information
- Security controls
- Organizational responsibilities
- Continual improvement
- Confidentiality
- Integrity
- Availability

Official reference:

https://www.iso.org/standard/27001

## Important Assessment Note

The VORTEX SECURE environment is a simulated enterprise environment created for this portfolio project.

The references listed here provide recognized security frameworks and guidance used to structure the assessment.

The project does not claim that VORTEX SECURE is formally certified against ISO/IEC 27001, nor does it claim formal compliance with any specific jurisdictional regulation.

The assessment uses these frameworks as professional reference points for security analysis, risk assessment, control evaluation, and recommendations.
