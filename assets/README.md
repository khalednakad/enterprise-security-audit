# Assets

This directory contains the primary technical assets created and used as supporting evidence for the VORTEX SECURE Enterprise Security Audit project.

The assets are designed to support the audit documentation, risk assessment, security controls, findings, recommendations, and final audit report.

## Enterprise Network Architecture

### Enterprise-Network-Diagram.drawio

The editable source file of the VORTEX SECURE enterprise network architecture diagram.

The diagram represents the company's hybrid enterprise security architecture, including:

- Internet connectivity
- Dual ISP architecture
- DDoS protection
- Next-Generation Firewall (NGFW)
- Web Application Firewall (WAF)
- Intrusion Detection and Prevention Systems (IDS/IPS)
- Load Balancer
- DMZ
- Internal Network
- Data Center
- Cloud Environment
- Microsoft 365
- Identity and Access Management
- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Privileged Access Management (PAM)
- Network Access Control (NAC)
- Endpoint Detection and Response (EDR)
- Extended Detection and Response (XDR)
- Security Operations Center (SOC)
- SIEM
- SOAR
- Threat Intelligence
- Threat Hunting
- Incident Response
- Backup and Disaster Recovery
- AI Compute Cluster
- Foundation Models
- Fine-tuned Models
- AI Agents
- RAG infrastructure

The architecture also reflects the security principles and controls considered throughout the audit, including Zero Trust, least privilege, network segmentation, continuous monitoring, encryption, backup, and continuous security assurance.

### Relationship to the Audit

The network architecture is used as a technical reference during the security assessment to understand:

- Network boundaries and trust zones
- Critical infrastructure
- Internet-facing services
- Internal systems
- Security control placement
- Identity and access boundaries
- Data protection zones
- Monitoring and detection capabilities
- Cloud and hybrid infrastructure
- AI infrastructure and associated security boundaries

The diagram therefore supports the assessment of risks, vulnerabilities, security controls, and potential attack paths identified during the audit.

## File Formats

The `.drawio` file is the editable source of the architecture diagram and can be opened and modified using diagrams.net.

The rendered visual version of the architecture is maintained separately in the `images/` directory.
